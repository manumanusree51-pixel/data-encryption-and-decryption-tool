📊 Algorithm Information

Learn about the encryption technology used.

AES-256-GCM

AES-256 uses a 256-bit key. GCM also authenticates encrypted data to detect unauthorized changes.

Secret Key

The key must be kept private. You need the same key to decrypt the data.

Initialization Vector

A fresh random 12-byte IV is generated for every encryption operation.

Privacy

Encryption happens locally in the browser. This demonstration does not upload files to a server.
